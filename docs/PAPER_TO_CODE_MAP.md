# Paper-to-code map

| Method | Paper and source checked | Main implementation | Fidelity assessment |
|---|---|---|---|
| DFME | `paper/DFME.pdf`; [official source](https://github.com/Yueeeeeeee/RecSys-Extraction-Attack), commit `47f841b708eb25d3aa996aefcbdfba6b713741b3` | `src/atrs/attacks.py`: `generate_dfme`, `pairwise_loss`, `distill_epoch` | Autoregressive Top-K generation, source-style T-1 retained prefixes, and summed adjacent/negative hinge objectives implemented. Ranking-only access is enforced. Numerical equivalence to the official training pipeline is unverified. |
| BECOME | `paper/BECOME.pdf`; [official source](https://github.com/Loche2/BECOME), commit `83355ef723e16ca826d013c23938f51f0e0b453e` | `src/atrs/attacks.py`: `generate_become`, `_frequency_choice`, weighted `pairwise_loss` | Feedback selection, staged continuation, rank/frequency sampler, weighted ranking and negatives implemented. Paper does not give all schedule parameters. Source sets `beta=1`, disabling its negative term; this implementation uses the paper's weighted objective and records the difference. |
| Sim4Rec | `paper/Sim4Rec.pdf`; [AAAI paper](https://ojs.aaai.org/index.php/AAAI/article/view/33392). No matching official code located as of 2026-10-15. | `src/atrs/attacks.py`: CSG penalties, GRU MLE, terminal REINFORCE, memory bank, `listwise_loss` | Paper-based independent implementation. The query allocation and some unspecified optimizer details are adaptations; do not claim exact reproduction. |
| GRO | `paper/GRO.pdf`; [arXiv paper](https://arxiv.org/abs/2310.16335). The code URL printed in the PDF was unavailable as of 2026-10-15. | `src/atrs/gro.py`: swap matrix, student gradient, rowwise best-gradient target, swap hinge, joint update | Core Eq. 4-6 workflow implemented. Applying it to SASRec rather than the original BERT4Rec is a backbone adaptation. No official-code equivalence claim. |
| Shared SASRec | [DFME](https://github.com/Yueeeeeeee/RecSys-Extraction-Attack) and [BECOME](https://github.com/Loche2/BECOME) model/dataloader sources | `src/atrs/model.py`, `src/atrs/training.py` | Structure, lengths, positional embedding, causal mask, tied output scores, sliding windows, BCE verified against source. Fresh code; exact parameter and training parity unverified. |
| Data/API/evaluation | All four papers' setup sections and the two extraction repositories | `src/atrs/data.py`, `api.py`, `evaluation.py`, `cli.py` | Common comparison protocol. Paper-native and unified outputs remain labelled separately. |

The public DFME and BECOME repositories did not contain a license file in the inspected checkout. Their code was used as a reference, not copied into this project. The unrelated `sb-ai-lab/Sim4Rec` simulator is not the AAAI extraction attack.
